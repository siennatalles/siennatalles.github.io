Optiver Realized Volatility Prediction Competition

Problem, approach & result
Problem

Kaggle Code competition: given order book and trade data from a fixed 10-minute window, predict the realized volatility of the next 10-minute window, across 429,000 windows spanning 112 stocks.

Approach

Earnings Announcement Effects on Options Implied Volatility

Confirmed near-term options carry higher implied volatility around earnings announcements (p = 0.01)
PythonyfinancePandasSciPy Statistical TestingData Visualization
Problem, approach & result
Problem

Do options expiring shortly after a company's earnings announcement carry higher implied volatility than later-dated options on the same stock, and how does it evolve as the announcement approaches?

Approach
  • Pulled live option chains and earnings dates for 31 large-cap tickers across technology, financials, healthcare, energy, and consumer sectors via the yfinance API
  • Classified options as near-term or far-term relative to each ticker's earnings date, and computed at-the-money implied volatility for each
  • Engineered an event-variance metric to isolate the earnings-specific effect from normal volatility term structure, validated with a one-sided t-test
  • Built an automated daily pipeline tracking the same option through its earnings announcement
Result
  • Confirmed near-term options carry significantly higher implied volatility around earnings (p = 0.01), with daily tracking showing implied volatility rising into the announcement and dropping sharply afterward

Student Performance Analytics

Caught a data leakage bug, then found attendance and internet access were the real predictors
With teammates Gabi Wurgaft, Harrison Arons, Ryan Pemberton, and John Collett
RLinear RegressionModel DiagnosticsVIF Model SelectionWLS
Problem, approach & result
Problem

Modeled students' overall scores for 10,000 students from a Kaggle dataset of study habits, attendance, and background factors. An initial model returned a suspicious R² of 1: this was target leakage, since the scores were actually a weighted sum of sub-scores that were still included as predictors, so the model was just recovering its own answer.

Approach
  • Removed the leaking features, then tested the corrected model for violations of standard regression assumptions
  • Checked for multicollinearity between predictors
  • Used several model-selection methods, including stepwise AIC, to find the best-fitting model
Result
  • All the model-selection methods pointed to the same two predictors, attendance percentage and internet access, as the strongest fit, with a lower AIC than the full model that included every feature
